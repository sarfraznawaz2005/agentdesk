# AgentDesk

A cross-platform desktop application where autonomous AI agent teams handle the full software development lifecycle — planning, coding, reviewing, and testing — while humans approve plans and deployments only.

**Motto: 99% agent-driven. Humans approve, deploy, and communicate.**

## Download

**[Latest release](https://github.com/sarfraznawaz2005/agentdesk/releases/latest)**

### Windows

One-line install (avoids a SmartScreen warning from the unsigned installer):

```powershell
irm https://raw.githubusercontent.com/sarfraznawaz2005/agentdesk/main/install.ps1 | iex
```

Or download `AgentDesk-win-x64-Setup.zip` (installer) or `AgentDesk-win-x64-portable.zip`
(no install required) from the [latest release](https://github.com/sarfraznawaz2005/agentdesk/releases/latest).

### macOS (Apple Silicon)

Download `AgentDesk-mac-arm64.zip` from the [latest release](https://github.com/sarfraznawaz2005/agentdesk/releases/latest), unzip, and drag `AgentDesk.app` to `/Applications`.

### Linux (x64)

Download `AgentDesk-linux-x64.tar.gz` from the [latest release](https://github.com/sarfraznawaz2005/agentdesk/releases/latest) and extract.

## What it does

AgentDesk manages software development projects through a team of specialized AI agents orchestrated by a Project Manager (PM) agent. The PM talks to you, creates plans, spawns sub-agents, and manages a kanban board — you approve plans and deployments, the agents do the rest.
